## What's new
- Dropdown place pickers (list narrows to places connected by a bus)
- 8 demo buses on South Goa routes with fake plates, bays and service hours
- One fare on every bus: students ₹5 half / ₹10 full, adults ₹10 half / ₹20 full; plus a "last bus" late-night alert
- Alternative transport: pilot, auto and cab driver lists with call and chat (fares discussed with the driver), and a walk tip for short trips
- Report a problem (passenger) feeding a Complaints page in Admin
- Safe waiting tips, "Share my trip" and "alert me at 2 min"
- Language switcher: English, Konkani, Hindi, Kannada (demo translations)
- SOS button with trusted contacts (set in Profile)
- Admin can add routes; new routes appear in passenger dropdowns (includes Margao → Mobor, St. Francis Xavier)
